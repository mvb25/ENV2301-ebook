# Chapter 10 — fully integrated Quarto edition

Copy the contents of this folder to the root of `mvb25/ENV2301-ebook` and replace `_quarto.yml`. Then commit and push through GitHub Desktop.

The Chapter 10 Quarto source includes seven write-before-reveal exercises, ten expandable sections (four boxes and six method guides), and an interactive four-question research-method decision key. Its CSS and JavaScript files load only on the Chapter 10 page. All nine illustrations are in `chapter10-assets/`.

This edition replaces the earlier installation kit that presented a separate interactive HTML page. Do not install both kits. This package does not include the standalone HTML file because the functionality now belongs directly to the Quarto chapter.

The original chapter wording and figures are substantially preserved, with small technical updates to references to the former standalone interactive edition. Figure values remain illustrative where labelled. The full build should be tested using the GitHub Actions workflow before relying on the published chapter.
